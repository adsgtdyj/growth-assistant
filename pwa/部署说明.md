# AI成长助理云端 PWA 部署说明

## 这个版本是什么

这是可以放到极空间 Docker 里运行的云端版。

手机访问极空间的 HTTPS 地址后，可以添加到桌面，像 App 一样使用。

## 目录说明

```text
habit-cloud-pwa/
  server.js              服务入口
  public/                手机页面和 PWA 文件
  data/                  云端数据保存目录
  package.json           服务需要的工具清单
  Dockerfile             Docker 构建文件
  docker-compose.yml     Docker 启动配置
  .env.example           设置模板
```

## 管理员账号

管理员账号通过环境设置文件填写：

```text
ADMIN_USERNAME=admin
ADMIN_PASSWORD=请改成你自己的强密码
```

不要把真实密码提交到 GitHub。

## 极空间部署步骤

1. 把整个 `habit-cloud-pwa` 文件夹上传到极空间。
2. 复制 `.env.example` 为 `.env`。
3. 在 `.env` 里填写：

```text
PORT=3001
NODE_ENV=production
DATA_DIR=/app/data

ARK_API_KEY=你的火山方舟API Key
ARK_ENDPOINT=https://ark.cn-beijing.volces.com/api/v3/chat/completions
ARK_MODEL=你的推理接入点ID

ADMIN_USERNAME=admin
ADMIN_PASSWORD=你自己的强密码
SESSION_SECRET=一串很长的随机字符
```

4. 在极空间 Docker 中使用 `docker-compose.yml` 启动。
5. 容器端口是 `3001`。
6. 极空间远程访问请指向这个容器的 `3001` 端口。
7. 手机打开 HTTPS 远程访问地址。
8. 登录后，如果检测到旧数据，会提示上传到云端。
9. 添加到手机桌面。

## 数据保存位置

数据会保存在：

```text
data/cloud-data.json
```

这个目录已经通过 Docker 挂载出来，容器重建后数据不会丢。

## 注意事项

1. 尽量使用 HTTPS 地址访问，否则 PWA 安装和离线缓存可能不稳定。
2. 不要把 `.env` 发给别人，里面有 AI 密钥和登录密码。
3. 当前第一版是单用户版本，后续再扩展家人朋友账号。
4. 当前数据保存使用 JSON 文件，适合第一版自用；多人长期使用时再升级为数据库。
